Advanced Intelligent Special Home Assistant
(A.I.S.H.A)
A.I.S.H.A (Advanced Intelligent Special Home Assistant) is a Python-based intelligent desktop
application designed to provide an integrated AI-powered assistant experience. The system
combines modern GUI design, secure authentication, AI-driven text and image understanding, and
voice interaction within a single platform.

Key Features- 
Secure user authentication with OTP-based email verification- AI-powered chat using large-scale cloud language models- Image-to-text and multimodal prompt processing- Voice-to-text interaction for hands-free operation- Modular multi-page GUI architecture


Technology Stack
Frontend / GUI: Python, CustomTkinter, Tkinter
Backend & Database: MySQL
Email & OTP Service: SendinBlue API (sib_api_v3_sdk)
AI Models:- gpt-oss:120b-cloud (Text prompting & conversational AI)- qwen3-vl:235b-cloud (Image-to-text and multimodal prompting)
Voice Processing: PyAudio, SpeechRecognition


Use Cases
A.I.S.H.A can be used as a personal desktop assistant, an AI-powered chat system, or a foundation
for intelligent home or office automation solutions. Its modular design allows easy expansion with
additional AI models and services.


Project Goal
The primary goal of this project is to demonstrate the practical integration of modern AI
technologies with desktop applications, focusing on usability, scalability, and secure user
interaction
